# Handoff

The vertical slice is complete and locally verified. It contains the avatar/name setup, one responsive office, click-to-walk, four colleagues, two three-choice conversations, environmental hotspots, muted audio, keyboard support, reduced motion, modal focus handling, and asset-load recovery.

Run with `npm install` followed by `npm run dev`. The Vite base is `/kontoret/`; the production output is generated by `npm run build`.

The larger story, psychology model, consequences, result archetypes, sharing, persistence, and deployment are deliberately not started. That boundary follows the user's request to validate the playable pixel-art slice first.

Known non-blocking production work is tracked in `BACKLOG.md`.
